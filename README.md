# IT Support Tracker — Demo

An independent React/Vite portfolio prototype for patch status, server upgrades and task coordination. All devices, dates, team labels and tasks are fictional. This is not an official Mazda system and contains no employer records.

## Features

- Filter the patch list by risk.
- Cycle a device's patch status.
- View fictional server upgrades and task categories.

## Run

Use Node.js 20.19+ or 22.12+. Run `npm ci`, then `npm run dev`. Build with `npm run build`; preview with `npm run preview`.

## Scope

A frontend demonstration with in-memory state. It does not patch devices, connect to an employer network, persist tickets or provide access controls. Status changes reset on reload. Use only fictional data when sharing screenshots or demonstrations. Environment files are ignored; this prototype requires no secrets.
